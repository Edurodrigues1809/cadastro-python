# Página de Cadastro
Sistema de cadastro em Python com interface gráfica CustomTkinter e exportação para Excel
Este é um projeto desenvolvido inteiramente em Python, utilizando a biblioteca Custom Tkinter para a construção da interface gráfica. O sistema permite realizar o cadastro de usuários através de uma interface moderna e intuitiva. Além disso, cada cadastro realizado é automaticamente salvo em uma planilha do Excel, permitindo o armazenamento e a organização dos dados de forma simples e acessível.
